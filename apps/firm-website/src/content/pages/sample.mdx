# Sample MDX Content

This is a sample MDX file to test the MDX configuration.

## Using UI Components

Here are some of the UI components mapped in `mdx-components.tsx`:

### Button Component

<Button variant="default">Click Me</Button>

<Button variant="outline">Outline Button</Button>

### Card Component

<Card>
  <CardHeader>
    <CardTitle>Card Title</CardTitle>
    <CardDescription>This is a card description</CardDescription>
  </CardHeader>
  <CardContent>
    <p>This is the card content area where you can put additional information.</p>
  </CardContent>
  <CardFooter>
    <Button variant="ghost">Action</Button>
  </CardFooter>
</Card>

### Accordion Component

<Accordion>
  <AccordionItem value="item-1">
    <AccordionTrigger>What is MDX?</AccordionTrigger>
    <AccordionContent>
      MDX is a format that combines Markdown with JSX, allowing you to use React components directly in your markdown content.
    </AccordionContent>
  </AccordionItem>
  <AccordionItem value="item-2">
    <AccordionTrigger>Why use MDX?</AccordionTrigger>
    <AccordionContent>
      MDX enables you to create rich, interactive content by leveraging the full power of React components within your documentation.
    </AccordionContent>
  </AccordionItem>
</Accordion>

### Container and Section

<Section>
  <Container maxWidth="lg">
    <p>This content is wrapped in a Container with maxWidth="lg" inside a Section.</p>
  </Container>
</Section>

- List item 1
- List item 2
- List item 3

**Bold text** and *italic text* work as expected.
